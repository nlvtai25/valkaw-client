# Security Policy

## Supported Versions

The following project components currently receive security updates:

| Component | Version | Supported |
| --------- | ------- | -------- |
| Valkaw Client | 1.0.6 | :white_check_mark: |
| Valkaw Launcher | 1.0.9 | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Valkaw Client or the Valkaw Launcher, please report it privately to the project maintainer before any public disclosure.

Please include:

- A clear description of the issue and its impact
- Steps to reproduce
- The affected version(s)
- Any suggested mitigation (optional)

We will acknowledge your report within 7 business days and keep you informed of progress toward a fix.

## Scope

Valkaw is a client-side Minecraft mod and launcher. Out of scope for security reports:

- Issues in third-party mods bundled inside the client jar (report those to their own authors)
- Issues in Minecraft itself or the Fabric loader
- Social engineering, phishing, or account theft unrelated to Valkaw code

## Policy

We do not offer bounties, but we credit reporters in release notes when a fix is released.
